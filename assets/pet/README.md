# 宠物素材说明

把素材放进本目录，再把 `manifest.example.json` 复制为 `manifest.json` 并按实际情况修改，重启后生效。
**没有 `manifest.json` 时，程序会显示用代码绘制的占位小团子。**

## 目录结构示例

```
assets/pet/
├── manifest.json
├── idle/        001.png 002.png ...
├── walk/        001.png 002.png ...
├── sleep/
├── drag/
├── talk/
└── happy.png    （也可以用精灵图）
```

## 动作列表

| 动作    | 触发时机                     | 是否必须 |
|---------|------------------------------|----------|
| `idle`  | 待机                         | **必须** |
| `walk`  | 随机在任务栏上方走动         | 可选     |
| `sleep` | 60 秒无交互                  | 可选     |
| `drag`  | 被鼠标拖起、下落过程中       | 可选     |
| `talk`  | GPT 回复过程中               | 可选     |
| `happy` | 被点击（身体）               | 可选     |
| `pat`   | 点击头部，播放一次           | 可选     |
| `dislike` | 点击腿部，播放一次         | 可选     |
| `jump`  | 待机时随机蹦跳，播放一次     | 可选     |
| `peek`  | 走到屏幕边缘时随机贴边偷看   | 可选     |
| `lie`   | 待机时随机躺下               | 可选     |
| `read`  | 待机时随机读书               | 可选     |
| `fall`  | 被甩出去、在空中下落         | 可选     |
| `land`  | 落地速度较大时摔坐再站起，播放一次 | 可选 |
| `dizzy` | 落地速度特别大时摔晕，接在 land 后播放一遍 | 可选 |
| `look`  | 左右张望，只在右键「播放动作」里播放 | 可选 |
| `gaze`  | 鼠标在旁边移动时看向鼠标（360°），帧排列见 `directions` / `steps` | 可选 |
| `type`  | 开启「跟着我打字」后，每按一次键推进几帧 | 可选 |
| `think` | 发消息后等待回复             | 可选     |
| `wave`  | 白天/晚上启动时问候，播放一次 | 可选    |
| `stretch` | 早上启动时伸懒腰，播放一次 | 可选     |
| `yawn`  | 深夜启动时、深夜待机时偶尔打哈欠，播放一次 | 可选 |
| `eat`   | 投喂后吃东西，播放一遍       | 可选     |
| `refuse` | 吃饱了还投喂时拒绝，播放一次 | 可选    |
| `hungry` | 饱食度低时待机随机饿肚子    | 可选     |
| `sad`   | 好感度低时待机随机委屈，很久没互动时启动后一直委屈到有互动 | 可选 |
| `love`  | 好感度升级，播放一次         | 可选     |

缺失的动作会自动使用 `idle`。

## manifest.json 字段

| 字段        | 说明                                                       |
|-------------|------------------------------------------------------------|
| `width` / `height` | 素材原图尺寸（像素）。设置里的体型「大」按此物理像素 1:1 显示，「中」「小」分别为 75%、50% |
| `facing`    | 素材默认朝向，`right` 或 `left`，向另一侧走时自动水平翻转 |
| `pixelArt`  | 像素风素材设为 `true`，放大时不会模糊                      |
| `walkSpeed` | 走动速度（每帧移动像素数）                                  |
| `actions`   | 各动作配置，见下                                           |

每个动作二选一：

- **帧序列**：`"frames": "目录名"`，读取目录下所有 png/webp/jpg，按文件名自然排序（`1.png, 2.png, 10.png` 顺序正确）。
- **精灵图**：`"sheet": "文件名"` + `frameWidth` + `frameHeight` + `count`，帧从左到右、从上到下排列。

公共字段：`fps` 帧率；`loop` 为 `false` 时播放到最后一帧后停住。

`gaze` 额外的 `directions`、`steps` 字段：第 1 帧为正面，之后按方向依次排列，每个方向 `steps` 帧（从正面附近到最大角度）；方向从画面右侧开始顺时针均分为 `directions` 份。例如 `directions: 24, steps: 8` 共 1 + 24 × 8 = 193 帧，第 2~9 帧看右侧、第 10~17 帧看右偏下 15°，以此类推。按鼠标相对头部的方向和距离取相邻方向、相邻幅度的 4 帧，转头连续不跳格；没有 `gaze` 时不跟随鼠标。

`gaze` 可选的 `flows`、`flowScale` 字段：`flows` 为光流目录（用 `scripts/build-gaze-flow.py` 从帧表生成），每个帧号 n（2 ~ 1 + directions × steps）有两张：`<n>a.webp` 为 (方向 a, 幅度 m) → (a+1, m) 的方向光流，`<n>m.webp` 为 (a, m-1) → (a, m) 的幅度光流（m=1 时从正面帧开始）；`flowScale` 为生成时的光流编码倍数（默认 2）。有光流时用 WebGL 先按幅度光流、再按方向光流把相邻 4 帧变形后混合，没有重影；没有光流或不支持 WebGL 时退回淡入淡出。

`icons/` 目录放投喂的食物图标 `food_<名称>.png`（名称见 `main.js` 的 `FOODS`）和爱心 `status_heart.png`。

## 素材建议

- 使用**透明背景 PNG**，不要白底。
- 同一动作的每帧尺寸一致，角色脚底位置对齐，否则播放时会抖动。
- 角色脚底贴近图片底边，这样宠物才会"站"在任务栏上。
