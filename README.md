# GPT小龙娘桌面版（源码）

一只住在 Windows 桌面上的龙娘桌宠，基于 Electron，接入 OpenAI 兼容的 Chat Completions 接口。这里是源码仓库；安装包下载和使用说明见发布页 [hkk1121/hkking-desktop](https://github.com/hkk1121/hkking-desktop)。

> 作者：hkking，使用 AI 制作（vibe coding）：hkking 提需求、试用和把关，代码和文档由 AI 编写。

素材制作相关的文件也在仓库里：`output/`（角色设定图和提示词）、`动画素材参考/`（参考图和动画提示词）、`scripts/`（视线跟随帧的生成脚本，运行前把环境变量 `COMFYUI_DIR` 设为装有 ComfyUI-Frame-Interpolation 节点的 ComfyUI 目录）。原始动画帧 `raw/` 和中间文件 `tmp/` 约 2GB，没有放进仓库。

## 运行

动画素材 `assets/pet/` 约 1GB，没有放进仓库（仓库里只有 `README.md` 和清单）。素材已随安装包分发：安装后在安装目录的 `resources/app.asar` 里，用 `npx @electron/asar extract app.asar <输出目录>` 解包，把其中的 `assets/pet` 复制到本目录即可。

```bash
npm install
npm start
```

也可以双击 `启动桌宠.bat` 启动（没装依赖时会先 `npm install`）。

首次启动会弹出设置窗口，填入 API Key 后会自动读取接口可用的模型，在下拉框里选择即可（也可以手动填写模型名）。设置里可以切换体型（小 / 中 / 大，大档为素材原图大小，4K 屏下也不糊），也可以把桌宠固定在 ChatGPT 桌面版窗口里（站在窗口底部、跟随窗口移动和最小化），或释放到桌面；桌面模式下前台进入全屏时默认隐藏、退出全屏后自动出现，开启「全屏时保持显示」则会压在无边框全屏游戏上面（独占全屏无法覆盖）。接了多块屏幕时，可以在设置里指定「活动屏幕」，桌宠只在这块屏幕上活动。系统代理没开时，可以在设置里填写代理地址（检查更新也走这个代理）。设置里还可以关闭语音、调节语音音量，查看当前版本、检查更新。点「人设设定」进入单独的一页，设置她的名字、怎么称呼你、人格设定、说话风格，以及记忆条数、长期记忆、主动搭话。配置保存在 `%APPDATA%/GPT桌宠/config.json`，最近的对话保存在 `%APPDATA%/GPT桌宠/history.json`（重启后还在，右键「清空对话记忆」清空）。

## 打包和发布

打包为安装包（输出到 `dist/`，素材会一起打进去，更换素材后需重新打包）：

```bash
npm run build:setup
```

输出 `GPT-DragonPet-Desktop-Setup-<版本号>.exe`、同名的 `.blockmap` 和 `latest.yml`，打包完会把安装包另复制一份到上一级目录，命名为 `GPT小龙娘桌面版-v<版本号>.exe`（`scripts/copy-setup.js`）。`npm run build` 打的是单文件免安装版 `dist/GPT桌宠.exe`，免安装版不能应用内更新。

发布：安装包发布在公开仓库 [hkk1121/hkking-desktop](https://github.com/hkk1121/hkking-desktop)。

1. 把 `package.json` 的 `version` 改成新版本号（三段式，如 `1.0.1`），重新打包。
2. 在公开仓库的 Releases 新建 `v<版本号>` 标签的版本，上传 `dist/` 里的安装包、`.blockmap` 和 `latest.yml` 三个文件，正文写更新说明（应用内更新弹窗会显示）。
3. 旧版本的 Release 不要删：增量下载要用到旧版本的 `.blockmap`，只下载改动的部分。

应用启动时会静默检查一次更新，设置页也可以手动检查。检查更新用的是 `electron-updater`，读取的仓库由 `package.json` 的 `build.publish` 配置；安装包没有代码签名，Windows 不要求签名也能覆盖安装。

## 交互

| 操作           | 效果                          |
|----------------|-------------------------------|
| 左键点击宠物   | 开心一下（聊天从右键菜单「和我聊天」进入） |
| 点击头部       | 摸头，加一点好感度             |
| 点击腿部       | 嫌弃地挪开腿                  |
| 拖拽宠物       | 拎起来，松手后按甩动的速度飞出去，碰到屏幕边缘反弹，落地重时摔坐在地上，特别重时摔晕 |
| 鼠标在旁边移动 | 360° 看向鼠标所在方向（可在右键菜单或设置里关闭「跟随鼠标」） |
| 鼠标在屏幕左、右、上边缘停一秒 | 从鼠标旁边那条边探出来偷看，鼠标走开后缩回去（可在右键菜单或设置里关闭「边缘偷看」） |
| 拖到屏幕左、右、上边缘附近松手 | 固定在那条边上偷看，点击也不回来，拖出来才回来 |
| 右键宠物       | 菜单：饱食度/好感度、聊天、投喂、脱鞋 / 穿鞋（光脚时还有脱白丝 / 穿白丝）、播放动作、固定在 GPT 里、全屏时保持显示、走动开关、跟随鼠标、跟着我打字、清空记忆、设置、退出 |
| 双击气泡       | 关闭气泡                      |
| 托盘图标左键   | 显示/隐藏宠物                 |

空闲时会随机走动、蹦跳、躺下或读书，走到屏幕边缘时可能会躲在边缘偷看，60 秒无交互会睡觉。

**语音**：问候、摸头、投喂、拖动、落地、偷看、睡觉、被点醒、思考等时候随机说一句台词（`assets/voice/lines.json`，语音为同名序号的 mp3，微软晓伊音色合成），气泡显示同一句；上一句还没说完时不打断，宠物隐藏时不说话。

**聊天**：按人设设定的名字、人格和说话风格回复，每次都会带上当前时间、饱食度、好感度、穿着和正在做的动作；模型在回复开头选一个动作（开心、比心、挥手、委屈、打哈欠、躺下等），她边说边做。开启长期记忆后，超出记忆条数的旧对话每攒 10 条整理一次，记下你的喜好、习惯和你们的约定，之后聊天都会带上，记下的内容可以在人设设定页修改或清空。开启主动搭话后，20~40 分钟没聊天、你在用电脑（1 分钟内动过鼠标键盘）、她空闲时，由模型按人设决定要不要主动说一句（只有气泡，没有语音）。

启动时按时段问候（早上伸懒腰，白天和晚上挥手，深夜打哈欠催你睡觉）。发消息后在收到回复前会托腮思考。开启「跟着我打字」后，你打字时她会坐下来跟着敲键盘（只统计按键次数，不记录按了什么）。

**养成**：饱食度每 5 分钟下降 1 点（关掉程序期间也会下降），低于 30 时会饿肚子；饿到 0 时好感度也会慢慢下降，好感度低于 20 时会委屈。右键「投喂」可以喂食物：食物从头顶掉下来，吃完加饱食度和好感度；饱食度高于 90 时会拒绝，喂青椒会嫌弃并扣好感度。摸头、聊天也会加好感度，每 100 点升一级，升级时比心。超过一天没理她，下次启动时她会委屈地坐着等你。数值保存在 `%APPDATA%/GPT桌宠/stats.json`。

## 目录结构

```
main.js            主进程：窗口、托盘、拖拽/下落/走动、调用 GPT 接口
preload.js         渲染进程可用的 API
src/index.html     宠物窗口
src/renderer.js    动画状态机、行为决策、对话气泡
src/settings.*     设置窗口
assets/pet/        宠物素材，格式见 assets/pet/README.md
assets/voice/      台词（lines.json）和语音
assets/icon.png    托盘图标
```
